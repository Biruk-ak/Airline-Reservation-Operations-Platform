15. Airport Operations — station resources, curfew, NOTAMs
16. Flight Tracking — positions, ETA, anomalies
17. Weather Integration — METAR/TAF, impact scoring
18. Analytics — OTP, load factor, forecasts
19. Reporting — scheduled/regulatory exports
20. Admin Portal — users, config, feature flags, audits
